# Simulação experimental SEM_IA

SEM_IA é um rótulo simulado para testar o fluxo de dados. Os códigos foram gerados com IA, e sua origem é COM_IA. Os resultados dos testes e as métricas foram medidos nesta execução. Não há tempos de resolução humana nem trials reais SEM_IA.

- Soluções: `solucoes/`
- Resultados: `validacao/validacao_consolidada.csv`
- Evidências: `validacao/logs/` e `validacao/manifesto.json`

Os CSVs registram `tratamento=SEM_IA`, `tipo_registro=SIMULACAO`, `tratamento_original=COM_IA` e `origem_codigo=GERADO_COM_IA`.
